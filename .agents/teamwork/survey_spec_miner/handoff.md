## 2. Logic Chain

1. **Multi-Tenancy & Tenant Scoping**:
   - *Observation*: Class diagram and ERD designate `SchoolDoc` (`schools`) as root tenant, and `users`, `academicYears`, `majors`, `applications`, `attendances`, `logbooks`, `assessments`, `sosReports`, `visits`, `finalReports`, and `jobApplications` all contain `schoolId: string <FK>`.
   - *Logic*: Firestore rules must strictly enforce `request.auth.token.schoolId == resource.data.schoolId` on all reads and writes to prevent cross-school data leakage. Super Admin is distinguished by having `schoolId == null` (or role `super_admin`), granting platform-wide access.
2. **Platform-Level Company Model**:
   - *Observation*: ERD states `CompanyDoc` is platform-level, with `createdBySchoolId: string? <FK>`. Sequence diagram 3.15 and AC state company deletion is restricted to Super Admin only. Sequence diagram 3.13 states company updates are restricted to fields `name, address, lat, lng, geofenceRadiusMeters, jurusanAllowed, quota`.
   - *Logic*: Company records are shared across multiple schools. A single school admin can create or edit specific descriptive fields, but only a Super Admin can delete a company. Furthermore, `filledQuota` must NEVER be directly updated by client apps—it is exclusively incremented/decremented by the `onApplicationDecided` server trigger during application approval transactions.
3. **Two-Stage Registration Protocol**:
   - *Observation*: Diagram 3.4 & 3.5 show Siswa inputs NISN; system calls `lookupNisn` which queries pre-imported roster data. If valid and not registered, student creates Firebase Auth credentials; system then calls `completeRegistration` to atomically migrate roster info to `users/{uid}` and set `isRegistered: true`.
   - *Logic*: Prevents arbitrary user registration. Only students whose NISN pre-exists in the school's roster can register. The atomic move prevents race conditions and ensures unicity.
4. **Attendance Lifecycle & Security Gate**:
   - *Observation*: ERD defines attendance ID format as `id = uid_yyyyMMdd <PK>`. Activity diagram 3.26 and Sequence diagram 3.27 show Check-Out can only proceed if `logbookSubmitted == true`.
   - *Logic*: Document ID format guarantees strictly one attendance record per student per calendar day. Because `onLogbookCreated` sets `logbookSubmitted = true`, check-out cannot occur before daily logbook submission. Firestore Security Rules enforce `request.resource.data.checkOut == null || resource.data.logbookSubmitted == true`.
5. **Two-Stage Assessment & Talent Recommendation**:
   - *Observation*: ERD and Sequence diagram 3.39 show `assessments` has two evaluators: Pembimbing Instansi fills `technicalScore` and `behaviorScore`, followed by Guru Pembimbing filling `finalScore` and finalizing status to `'final'`. Trigger `onAssessmentFinalized` checks `finalScore >= school.talentThreshold` and sets `isRecommendedTalent = true`.
   - *Logic*: Decouples industry technical assessment from pedagogical assessment while automating talent pool identification based on the school's configured cutoff threshold.

## 3. Caveats

1. **Roster Storage Location**: The PRD diagrams depict roster data as pre-imported documents checked during registration. In multi-tenant Firestore, roster records can be placed either under a subcollection `schools/{schoolId}/roster/{nisn}` or a top-level collection `rosters/{schoolId_nisn}`. Both satisfy `lookupNisn` and `completeRegistration`; a root collection with composite ID or indexed `schoolId` + `nisn` is recommended for simple indexing.
2. **Local Emulator Environment**: In development/testing, Cloudflare R2 is replaced by a local S3-compatible mock (e.g. MinIO or an S3 emulator / mock Express server) running alongside Firebase Emulators. Presigned URLs must be formed against this local mock endpoint.
3. **QR Token Lifetime vs Mobile Clocks**: Dynamic QR codes expire every 60 seconds (`expiresAt`). A tolerance window of ±30 to 60 seconds should be accommodated on the server to prevent valid scans from failing due to minor mobile device clock skew.

  6. Function writes `attendances/{uid_yyyyMMdd}`:
     - `status: 'hadir'`
     - `logbookSubmitted: false`

## 9. Cloud Functions & Helper Modules Specifications

### Callable Cloud Functions

#### 1. `lookupNisn`
- **Type**: Callable Function (`onCall`)
- **Authentication**: Public / unauthenticated (used during pre-registration).
- **Input Signature**:
  ```typescript
  interface LookupNisnRequest {
    nisn: string; // 10 digits
  }
  ```
- **Validation**:
  - Regex test: `/^[0-9]{10}$/`.
  - Lookup in `roster` collection matching `nisn`.
- **Output Signature**:
  ```typescript
  interface LookupNisnResponse {
    status: 'valid' | 'already-registered' | 'not-found';
    data?: {
      name: string;
      nisn: string;
      schoolId: string;
      jurusanId: string;
      kelas: string; // e.g. "XII RPL 2"
    };
  }
  ```
- **Errors**:
  - `invalid-argument`: NISN format invalid.
  - `already-exists`: NISN already has `isRegistered: true`.
  - `not-found`: NISN does not exist in roster.

#### 2. `completeRegistration`
- **Type**: Callable Function (`onCall`)
- **Authentication**: Required (`context.auth.uid`).
- **Input Signature**:
  ```typescript
  interface CompleteRegistrationRequest {
    nisn: string;
  }
  ```
- **Behavior**:
  - Validates `context.auth` exists.
  - Reads `roster` record for `nisn`. Validates `isRegistered == false`.
  - In a Firestore transaction:
    1. Creates `users/{context.auth.uid}` with:
       ```typescript
       {
         uid: context.auth.uid,
         role: 'siswa',
         schoolId: roster.schoolId,
         jurusanId: roster.jurusanId,
         nisn: roster.nisn,
         name: roster.name,
         email: context.auth.token.email,
         kelas: roster.kelas,
         isRegistered: true,
         isActive: true,
         createdAt: FieldValue.serverTimestamp(),
         updatedAt: FieldValue.serverTimestamp()
       }
       ```
    2. Updates `roster` record setting `isRegistered: true`.
    3. Increments `schools/{roster.schoolId}.studentQuotaUsed` by 1.
- **Output**: `{ success: true, uid: string }`.

#### 3. `getUploadUrl`
- **Type**: Callable Function (`onCall`)
- **Authentication**: Required (`context.auth.uid`).
- **Input Signature**:
  ```typescript
  interface GetUploadUrlRequest {
    filename: string;
    contentType: 'image/jpeg' | 'image/png' | 'application/pdf';
    folder: 'logbooks' | 'finalReports' | 'avatars';
  }
  ```
- **Behavior**:
  - Validates MIME type and allowed folder.
  - Generates secure S3 key: `${folder}/${context.auth.uid}/${Date.now()}_${uuid()}_${sanitizedFilename}`.
  - Calls `r2.ts` to generate presigned S3 PUT URL with 5-minute expiry (300 seconds).
  - Returns presigned upload URL and public download URL.
- **Output Signature**:
  ```typescript
  interface GetUploadUrlResponse {
    uploadUrl: string; // Presigned PUT URL
    fileUrl: string;   // Permanent public/CDN URL
    key: string;       // Storage object key
  }
  ```

### Firestore Triggers

#### 4. `verifyAttendance`
- **Type**: Callable Function or Firestore Trigger (`onCall` recommended for atomic response to mobile check-in).
- **Input Signature**:
  ```typescript
  interface VerifyAttendanceRequest {
    companyId: string;
    token: string;
    coords: {
      lat: number;
      lng: number;
    };
  }
  ```
- **Behavior**:
  1. Reads `qrTokens/{companyId}`: checks `token === request.token` and `expiresAt.toMillis() > Date.now()`.
  2. Reads `companies/{companyId}`: calculates distance via `geo.ts` Haversine formula between `coords` and `company.{lat, lng}`.
  3. Asserts distance <= `company.geofenceRadiusMeters` (default 50).
  4. Writes `attendances/${uid}_${todayStr}` with `status: 'hadir'`, `checkIn: { time: now, distanceMeters: dist, verifiedServerSide: true }`.
- **Output**: `{ success: true, distanceMeters: number }`.

#### 5. `verifyCheckout`
- **Type**: Callable Function (`onCall`).
- **Input Signature**:
  ```typescript
  interface VerifyCheckoutRequest {
    companyId: string;
    token: string;
    coords: {
      lat: number;
      lng: number;
    };
  }
  ```
- **Behavior**:
  1. Reads today's attendance document `attendances/${uid}_${todayStr}`.
  2. Asserts `attendance.logbookSubmitted === true`. Throws `failed-precondition` if false.
  3. Verifies QR token and geofence distance (<= 50m).
  4. Updates `attendances/${uid}_${todayStr}` with `checkOut: { time: now, distanceMeters: dist, verifiedServerSide: true }`.
- **Output**: `{ success: true, checkOutTime: string }`.

#### 6. `onLogbookCreated`
- **Type**: Firestore Trigger (`onDocumentCreated('logbooks/{id}')`)
- **Behavior**:
  1. Extracts `attendanceId` from newly created logbook document.
  2. Updates `attendances/{attendanceId}`: sets `logbookSubmitted: true`.
  3. Unlocks client-side check-out capability.

#### 7. `onLogbookReviewed`
- **Type**: Firestore Trigger (`onDocumentUpdated('logbooks/{id}')`)
- **Behavior**:
  1. Checks if `reviewStatus` changed from `'menunggu'` to `'disetujui'` or `'ditolak'`.
  2. Calls `notify.ts` to send notification to `users/{logbook.uid}/notifications`:
     - `title`: `reviewStatus === 'disetujui' ? 'Logbook Disetujui' : 'Logbook Ditolak'`
     - `body`: `logbook.catatan || 'Logbook harian Anda telah ditinjau.'`
     - `relatedPath`: `'/logbooks/' + id`

#### 8. `onApplicationDecided`
- **Type**: Firestore Trigger (`onDocumentUpdated('applications/{id}')`)
- **Behavior**:
  1. Triggers when `status` transitions from `'menunggu'` to `'disetujui'` or `'ditolak'`.
  2. If `'disetujui'`:
     - In transaction: checks `companies/{companyId}.filledQuota < quota`. Increments `filledQuota` by 1.
     - Updates `users/{application.studentId}` setting `companyId = application.companyId`.
  3. If `'ditolak'`:
     - Notifies student with `rejectionReason`.
  4. Dispatches notification via `notify.ts`.

#### 9. `onAssessmentFinalized`
- **Type**: Firestore Trigger (`onDocumentUpdated('assessments/{id}')`)
- **Behavior**:
  1. Triggers when `status` transitions to `'final'`.
  2. Reads `schools/{schoolId}.talentThreshold` (default 85).
  3. If `finalScore >= talentThreshold`: sets `isRecommendedTalent: true` on assessment.
  4. Notifies student of final assessment completion.

#### 10. `onSosStatusChanged`
- **Type**: Firestore Trigger (`onDocumentUpdated('sosReports/{id}')`)
- **Behavior**:
  1. Triggers when `status` or `followUpNote` updates on SOS report.
  2. Notifies student `users/{studentId}/notifications` with teacher's follow-up note.

#### 11. `markAbsentees`
- **Type**: Scheduled Cloud Function (`onSchedule('0 18 * * *')` - 18:00 daily).
- **Behavior**:
  1. Iterates over active placed students (`role == 'siswa' && isActive == true && companyId != null`).
  2. If today's attendance document does not exist, creates `attendances/${uid}_${todayStr}` with `status: 'alpha'`.

### Helper Libraries

#### `geo.ts`
- Haversine Distance Formula:
  $$\Delta\varphi = \frac{(\text{lat}_2 - \text{lat}_1) \cdot \pi}{180}, \quad \Delta\lambda = \frac{(\text{lon}_2 - \text{lon}_1) \cdot \pi}{180}$$
  $$a = \sin^2\left(\frac{\Delta\varphi}{2}\right) + \cos\left(\frac{\text{lat}_1 \cdot \pi}{180}\right) \cdot \cos\left(\frac{\text{lat}_2 \cdot \pi}{180}\right) \cdot \sin^2\left(\frac{\Delta\lambda}{2}\right)$$
  $$c = 2 \cdot \text{atan2}(\sqrt{a}, \sqrt{1 - a}), \quad d = R \cdot c \quad (R = 6,371,000\text{ m})$$
- Default Geofence Radius: `50` meters.
- Function: `isWithinGeofence(userLat, userLng, companyLat, companyLng, radiusMeters = 50): boolean`.

#### `notify.ts`
- Helper: `createNotification(uid: string, type: string, title: string, body: string, relatedPath?: string)`.
- Writes to `users/{uid}/notifications/{autoId}`.
- Sends FCM push notification if device registration token exists.

#### `r2.ts`
- Initializes AWS SDK `@aws-sdk/client-s3` with Cloudflare R2 credentials (or local S3-compatible mock URL during testing).
- Generates presigned URLs using `@aws-sdk/s3-request-presigner` (`PutObjectCommand`, `expiresIn: 300`).

## 10. Firestore Security Rules Constraints

All rules must satisfy multi-tenant isolation, role authorization, and state integrity:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Helper functions
    function isAuthenticated() {
      return request.auth != null;
    }
    function getUserData() {
      return get(/databases/$(database)/documents/users/$(request.auth.uid)).data;
    }
    function isSuperAdmin() {
      return isAuthenticated() && 
        (request.auth.token.role == 'super_admin' || 
         (request.auth.token.role == 'admin' && request.auth.token.schoolId == null) ||
         (getUserData().role == 'admin' && getUserData().schoolId == null));
    }
    function isAdminSekolah(schoolId) {
      return isAuthenticated() && 
        ((request.auth.token.role == 'admin' && request.auth.token.schoolId == schoolId) ||
         (getUserData().role == 'admin' && getUserData().schoolId == schoolId));
    }
    function isGuruPembimbing(schoolId) {
      return isAuthenticated() && 
        ((request.auth.token.role == 'guru pembimbing' && request.auth.token.schoolId == schoolId) ||
         (getUserData().role == 'guru pembimbing' && getUserData().schoolId == schoolId));
    }
    function isPembimbingInstansi(companyId) {
      return isAuthenticated() && 
        ((request.auth.token.role == 'pembimbing instansi' && request.auth.token.companyId == companyId) ||
         (getUserData().role == 'pembimbing instansi' && getUserData().companyId == companyId));
    }
    function isSiswa() {
      return isAuthenticated() && 
        (request.auth.token.role == 'siswa' || getUserData().role == 'siswa');
    }

    // 1. schools
    match /schools/{schoolId} {
      allow read: if isAuthenticated();
      allow write: if isSuperAdmin();
    }

    // 2. companies (Platform-level)
    match /companies/{companyId} {
      allow read: if isAuthenticated();
      allow create: if isSuperAdmin() || isAuthenticated() && getUserData().role == 'admin';
      allow update: if isSuperAdmin() || (
        isAuthenticated() && getUserData().role == 'admin' &&
        // Cannot modify filledQuota or createdBySchoolId directly
        request.resource.data.diff(resource.data).affectedKeys()
          .hasOnly(['name', 'address', 'lat', 'lng', 'geofenceRadiusMeters', 'jurusanAllowed', 'quota', 'updatedAt'])
      );
      // Strictly Super Admin only for delete
      allow delete: if isSuperAdmin();
    }

    // 3. qrTokens
    match /qrTokens/{companyId} {
      allow read: if isAuthenticated();
      allow write: if isPembimbingInstansi(companyId);
    }

    // 4. users
    match /users/{userId} {
      allow read: if isAuthenticated() && (
        request.auth.uid == userId ||
        isSuperAdmin() ||
        resource.data.schoolId == getUserData().schoolId
      );
      allow create: if isAuthenticated() && (request.auth.uid == userId || isSuperAdmin());
      allow update: if isAuthenticated() && (
        request.auth.uid == userId ||
        isSuperAdmin() ||
        isAdminSekolah(resource.data.schoolId)
      );
      allow delete: if isSuperAdmin();

      // Notifications subcollection
      match /notifications/{notificationId} {
        allow read, write: if isAuthenticated() && request.auth.uid == userId;
      }
    }

    // 5. applications
    match /applications/{appId} {
      allow read: if isAuthenticated() && (
        request.auth.uid == resource.data.studentId ||
        isAdminSekolah(resource.data.schoolId) ||
        isSuperAdmin()
      );
      allow create: if isSiswa() && 
        request.resource.data.studentId == request.auth.uid &&
        request.resource.data.status == 'menunggu';
      allow update: if isAdminSekolah(resource.data.schoolId) || isSuperAdmin();
      allow delete: if isAdminSekolah(resource.data.schoolId) || isSuperAdmin();
    }

    // 6. attendances
    match /attendances/{attendanceId} {
      allow read: if isAuthenticated() && (
        request.auth.uid == resource.data.uid ||
        isGuruPembimbing(resource.data.schoolId) ||
        isAdminSekolah(resource.data.schoolId) ||
        isSuperAdmin()
      );
      allow create: if isAuthenticated(); // Or via Functions
      allow update: if isAuthenticated() && (
        // Deny checkOut unless logbook is submitted
        (request.resource.data.checkOut == null || resource.data.logbookSubmitted == true) &&
        (request.auth.uid == resource.data.uid || isAdminSekolah(resource.data.schoolId))
      );
    }

    // 7. logbooks
    match /logbooks/{logbookId} {
      allow read: if isAuthenticated() && (
        request.auth.uid == resource.data.uid ||
        isPembimbingInstansi(resource.data.companyId) ||
        isGuruPembimbing(resource.data.schoolId) ||
        isAdminSekolah(resource.data.schoolId) ||
        isSuperAdmin()
      );
      allow create: if isSiswa() && 
        request.resource.data.uid == request.auth.uid &&
        request.resource.data.reviewStatus == 'menunggu';
      allow update: if isPembimbingInstansi(resource.data.companyId) &&
        request.resource.data.diff(resource.data).affectedKeys()
          .hasOnly(['reviewStatus', 'catatan', 'reviewedBy', 'reviewedAt', 'updatedAt']);
    }

    // 8. assessments
    match /assessments/{assessmentId} {
      allow read: if isAuthenticated() && (
        request.auth.uid == resource.data.studentId ||
        isPembimbingInstansi(resource.data.companyId) ||
        isGuruPembimbing(resource.data.schoolId) ||
        isAdminSekolah(resource.data.schoolId) ||
        isSuperAdmin()
      );
      // Stage 1: Pembimbing Instansi writes technical & behavior scores
      allow create, update: if isPembimbingInstansi(request.resource.data.companyId) ||
        isGuruPembimbing(request.resource.data.schoolId) ||
        isAdminSekolah(request.resource.data.schoolId);
    }

    // 9. sosReports
    match /sosReports/{sosId} {
      allow read: if isAuthenticated() && (
        request.auth.uid == resource.data.studentId ||
        isGuruPembimbing(resource.data.schoolId) ||
        isAdminSekolah(resource.data.schoolId)
      );
      allow create: if isSiswa() && 
        request.resource.data.studentId == request.auth.uid &&
        request.resource.data.status == 'belum-ditinjau';
      allow update: if isGuruPembimbing(resource.data.schoolId) || 
        isAdminSekolah(resource.data.schoolId);
    }

    // 10. finalReports
    match /finalReports/{reportId} {
      allow read: if isAuthenticated() && (
        request.auth.uid == resource.data.studentId ||
        isAdminSekolah(resource.data.schoolId) ||
        isSuperAdmin()
      );
      allow create: if isSiswa() && 
        request.resource.data.studentId == request.auth.uid &&
        request.resource.data.status == 'menunggu';
      // Admin update restricted to review fields & certificate
      allow update: if isAdminSekolah(resource.data.schoolId) &&
        request.resource.data.diff(resource.data).affectedKeys()
          .hasOnly(['status', 'certificateUrl', 'reviewNote', 'reviewedBy', 'reviewedAt', 'updatedAt']);
    }

    // 11-17: academicYears, majors, mentorships, visits, jobVacancies, jobApplications, roster
    match /academicYears/{id} { allow read: if isAuthenticated(); allow write: if isAdminSekolah(request.resource.data.schoolId); }
    match /majors/{id} { allow read: if isAuthenticated(); allow write: if isAdminSekolah(request.resource.data.schoolId); }
    match /mentorships/{id} { allow read: if isAuthenticated(); allow write: if isAdminSekolah(resource.data.schoolId); }
    match /visits/{id} { allow read: if isAuthenticated(); allow write: if isGuruPembimbing(resource.data.schoolId) || isAdminSekolah(resource.data.schoolId); }
    match /jobVacancies/{id} { allow read: if isAuthenticated(); allow write: if isPembimbingInstansi(request.resource.data.companyId); }
    match /jobApplications/{id} { allow read: if isAuthenticated(); allow create: if isSiswa(); allow update: if isPembimbingInstansi(resource.data.companyId); }
    match /roster/{id} { allow read: if true; allow write: if isAdminSekolah(request.resource.data.schoolId) || isSuperAdmin(); }
  }
}
```
